USER GUIDE

This window is where you assign the file columns and enter the values for the
DRDH determination. What DRDH and DRDC mean, and how they are computed, is in
the General manual.

Only three things are mandatory: Time, Reactivity and the position of the
first group (H12, in the 10-group mode H10). Everything else is optional and
extends the result.


1. Required parameters

    - Time              1 column
    - Reactivity        2 columns
    - Group positions   1 column each

In the 12-group mode there are 12 groups in total; in the 10-group mode there
are 10. The mode is switched in the "Mode settings" menu, and the current one
is shown above the parameter list.

The position of the first group (H12, or H10 in the 10-group mode) is
mandatory. Other groups may be added after it, but the assigned groups must
follow one another without a gap (e.g. H12, H11, H10); otherwise START reports
the order. A group that is not assigned is simply not taken into account.

The expected number of columns is shown next to each parameter name. A tick
in front of the name means the parameter is set.


2. Optional file column

Boric acid concentration (2 columns) lets the DRDC be determined from the
record itself, without entering the concentrations by hand.


3. Entered values

    - Group length, cm          the full stroke of a group
    - Overlap, %                the handover point between consecutive groups
    - DRDC, %/(g/kg)            the reference value, for the deviation
    - C(H3BO3) initial, g/kg    the concentration at the start
    - C(H3BO3) final, g/kg      the concentration at the end

Group length has a default and only needs changing if the stroke differs.
Overlap has a default too. It is the position (as read on its ruler) at which
the next group starts moving after the previous one; it is used only to place
the groups on the common axis of the DRDH plot, and does not change the
measured values. It can be any number - also more than 100 or below zero.

Requirements:
    - Numeric values; both "." and "," work as the decimal separator
    - Group length > 0, DRDC <= 0, concentrations not negative
    - Overlap: any number

Confirm a value with the button next to its field or with Enter. A tick
appears in the "Additional Parameters" field once it is accepted.


4. Assigning file columns

    1. Select a parameter in the combo box.
    2. Click the button(s) of the required data column(s). A click selects the
       column (the button stays pressed); a second click releases it.
    3. Press "Get a parameter" to confirm.
    4. Select the next parameter.

Parameters may be assigned in any order. Each column is checked against the
range expected for its parameter, so a column assigned to the wrong parameter
is reported rather than silently accepted.

The columns of an assigned parameter stay pressed and locked, so the same
column cannot be taken twice. If a parameter is assigned again, its previous
columns are released.


5. Additional (auxiliary) parameters

Any other file column can be shown on the plot of the processing window
without being used in the computation (e.g. a flow rate or a level).

    1. Select "Add new parameter" in the combo box.
    2. Click the button(s) of the column(s).
    3. Press "Get a parameter" and type a name for the parameter. The name is
       used for its scale and in the legend; it must not be empty or repeated.

If several columns are selected, you are asked to confirm: their mean is shown
as ONE parameter on a single scale. Numbers with a decimal comma are accepted;
empty cells are allowed. If you cancel the name dialog the columns stay
selected, so you can repeat it.

Any number of additional parameters can be added. In the processing window
each one gets its own scale to the right of the others; they are switched on
and off and renamed there (Plot -> Edit entries), and shown in the legend.


6. Checking and correcting

Menu "Parameters":

    - Show NFME parameters - a table "parameter - column(s)" of everything
      assigned so far, additional parameters included (they are shown as
      "Added: name").
    - Show computed parameters - a table "parameter - value" of the values
      entered so far.

Click a row to select it (several rows can be selected). "Clear" removes the
selected parameter(s), "Clear all" removes all of them. For an NFME parameter
its columns are released: the buttons are unpressed and enabled again, and
the tick in front of the name disappears. For a computed parameter the value is
dropped: the field returns to its default (the default Group length and
Overlap, empty for the others) and the tick disappears. The windows follow every
change, so they can stay open while you work.

Ctrl+Z undoes and Ctrl+Y (or Ctrl+Shift+Z) redoes the last actions: picking
a column, assigning or adding a parameter, entering a value, "Clear" and "Clear
all". It works with any keyboard layout, also while the "Parameters" windows
have the focus.


7. Mode settings

    - Switch 12 <-> 10 - switches between the 12- and the 10-group mode. In
      the 10-group mode H12 and H11 are removed from the list.
    - Movement type - a side submenu with Withdrawal and Insertion. It is not
      required (the direction is taken from the data) and may be left empty;
      "Not specified" clears it.


8. Launching

Press "START" once the mandatory parameters are set. If something is missing,
the missing names are listed instead. The "Parameters" windows are closed and
Ctrl+Z / Ctrl+Y are switched off while the processing window is open.


9. Menu

    - Parameters - the tables of the assigned and entered parameters
      (section 6).
    - Mode settings - see section 7.
    - INFO - this guide.


10. Navigation

"BACK" returns to the main menu. The selected columns, the entered values,
the added parameters, the group mode, the movement type and the undo history
are not preserved; the loaded file and the beta effective value are.

If you come back to this window with "BACK" of the processing window,
everything is exactly as you left it: the pressed buttons, the ticks, the
entered values, the additional parameters, the group mode and the movement
type. The parameters can be corrected and the determination repeated.
